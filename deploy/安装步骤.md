# Batocera 电影平台 · 安装步骤

把影视刮削接进 Batocera 的 EmulationStation 首页**独立「电影」分页**（海报网格 +
播放器走 VLC / mpv），并顺带设好 **Kodi 中文界面 + 影片库指向第三分区**、**VLC 中文字幕字体**。

> 本文是**照着做的操作手册**；「每件东西落到哪、为什么这么设计」见同目录 `DEPLOY.md`，
> 依赖 / 目录结构见 `README.md`。

---

## 0. 前提

- 一块 **Batocera 43.x** 的盘（U 盘 / 移动硬盘 / 迷你主机内的盘）。
- 整个 **`deploy/` 文件夹**（约 67MB，大头是 `payload/system/movies/batoscrape`）。
- **不需要另装运行时**：`batoscrape` 是 .NET 8 **自包含单文件**；`mpv / python3 / yad /
  Kodi 21 / VLC 3` 都是 Batocera **系统自带**。

---

## 1. 把 `deploy/` 拷到盘上（在 Windows 电脑上操作）

盘的 `/userdata` 分区在 Windows 里读不了，走网络传。二选一：

- **网络共享（最省事）**：资源管理器地址栏输入 `\\BATOCERA\share`
  （或 `\\<盘的IP>\share`，例如 `\\192.168.17.129\share`），把 `deploy` 文件夹整个拖进去。
  落到盘上就是 **`/userdata/deploy`**。
- **scp**：`scp -r deploy root@<盘的IP>:/userdata/`

> ⚠️ **必须放 `/userdata` 下**。Batocera 的 `/` 是内存盘（重启即失），写到 `/userdata`
> 以外的东西重启就没了。

---

## 2. 在盘上跑安装（需要 root）

SSH 进盘（`ssh root@<盘的IP>`），或直接在盘上的终端里：

```sh
sh /userdata/deploy/install.sh              # 全装（含 Kodi 中文 / VLC 中文字幕设置）
sh /userdata/deploy/install.sh --no-players # 只装刮削器 + 电影分页，不动 Kodi/VLC
```

**幂等，可反复运行**；已存在的 `scraper.json`（含你的 key）**不会被覆盖**。

安装脚本按 5 步走：

| 步骤 | 做什么 |
|---|---|
| 1/5 | 建目录：`/userdata/system/movies/{lib,icons}`、ES 配置目录、F1 应用目录 |
| 2/5 | 铺 `batoscrape` + `play.sh` / `scrape-gui.sh` / `settings.sh` + 图标，并 `chmod +x` |
| 3/5 | 写 `scraper.json`（已存在则保留；否则用空模板） |
| 4/5 | 注册 ES「电影」分页（`es_systems_movies.cfg`），并清理会让内置系统消失的旧文件 |
| 5/5 | 装 3 个 F1 快捷项（`batoscrape` / `vlc` / `kodi`），并清掉废弃的旧「刮削设置」项 |

末尾再跑 `players/setup-kodi.sh` + `players/setup-vlc.sh`（`--no-players` 可整段跳过）。

---

## 3. 配置（在盘上，用键盘 / 遥控）

**F1 菜单 →「电影刮削」** → 首次进去会**自动弹出设置**：

- **TMDB API Key 或 Read Token**（二填一）。注册：<https://www.themoviedb.org/signup>；
  申请：<https://www.themoviedb.org/settings/api>。被墙时在「代理」填
  `socks5h://127.0.0.1:10808`（对应本机 v2rayN 的默认 SOCKS5 端口）。
- 要下字幕 → 勾「**下载字幕**」，选**字幕源**：
  - **射手网(伪)·国内（默认，免翻墙）**：填它的 **32 位 Token**
    （登录 <https://assrt.net/usercp.php>「用户面板」复制，API 文档 <https://assrt.net/api/doc>）。
  - OpenSubtitles：填它的 **API Key**（注册后到
    <https://www.opensubtitles.com/en/consumers> 免费生成）。

点「保存」回到菜单（设置和刮削在同一个入口里，不单占菜单项）。

---

## 4. 放片 + 跑一次刮削

- **影片放 `/userdata/roms/movies`**（mergerfs 合成视图；**实体建议落第三分区**，
  如 `/media/sda3/roms/movies`，别塞 `sda2` 上的小系统分区）。
- 回到 F1 →「电影刮削」→「**开始刮削**」，跑一次：扫描 → 匹配元数据 → 下海报 →（可选）下字幕。
  日志在窗口里实时滚动。

---

## 5. 重启 ES（或整机）→ 首页出现「电影」分页

按 ←→ 翻到「电影」，选中影片回车即用播放器打开（**默认 VLC**，可 Ctrl+Q 退出；
另有 mpv 备选）。

---

## 6. 更新

```sh
curl -fsSL https://ghfast.top/https://raw.githubusercontent.com/anturong/batocera-movie-scraper/main/install.sh | bash
# 或已装过一次后：
bash /userdata/system/movies/install.sh --check
bash /userdata/system/movies/install.sh
```

更新只替换程序与菜单文件，**不动** `/userdata/system/movies/scraper.json` 和影片库。

---

## 7. 卸载

```sh
sh /userdata/deploy/uninstall.sh                 # 保留 scraper.json（含你的 key）
sh /userdata/deploy/uninstall.sh --purge-config  # 连 scraper.json 一起删
```

卸载**不动**影片库 / 海报，也不动 Kodi / VLC 的设置。

---

## Windows 电脑端（可选，是另一条独立的路）

Windows 端**不用安装**：双击 `deploy\windows\电影刮削器.exe`，界面里选电影文件夹、填
TMDB Key/Token/代理、选刮削核心、点「开始刮削」，实时日志在下方。设置存到同目录 `config.json`。
命令行版是 `deploy\windows\batoscrape.exe`。同样自带 .NET 运行时，目标机无需装 .NET。

---

## 几个别扭但重要的点（踩过的）

1. **开发目录里可能有含 key 的配置**：`payload/system/movies/scraper.json` 与
   `windows/config.json`（本机开发用，已 gitignore）。安装器**不会复制它们**，
   只用 `scraper.example.json` 生成空模板；已有 `scraper.json` 不会被覆盖。
   发布包由 `tools/make_release.py` 白名单 + 凭据扫描生成，不会带出去。
2. **Kodi 中文设置要求 Kodi 至少启动过一次**：`players/setup-kodi.sh` 在
   `.kodi/userdata` 不存在时会**跳过**。所以要么先手动开一次 Kodi 再跑 `install.sh`，
   要么事后单独跑 `sh players/setup-kodi.sh`。
3. **影片实体放第三分区**（最后那个大盘），别放系统小分区，否则很快写满。
4. **VLC 退出**：`play.sh` 里强制 `QT_QPA_PLATFORM=xcb` + `--vout xcb_x11`（VM / 软件 GL 下
   Qt 走 EGL 会 abort）。VLC 是有界面的，**Ctrl+Q** 或关窗口即可退出——不要改回
   `--intf dummy`（那种没有任何窗口能关掉它）。
5. **改完 ES 分页要重启 ES / 整机**才生效（ES 不热加载 `es_systems_*.cfg`）。
